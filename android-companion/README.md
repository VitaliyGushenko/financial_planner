# Планировщик — компаньон для Android

Тонкое приложение-мост: слушает уведомления выбранных банков, разбирает текст и записывает
операции в ваш аккаунт Firebase (тот же, что у веб-приложения). Интерфейс — по-прежнему в вебе.

## Что делает

- `NotificationListenerService` слушает только выбранные приложения.
- Разбирает уведомления формата БАПБ/Беларусбанк:
  - `OPLATA 62.46 BYN KARTA #1310 DATA 24.11.2026 21:06:56 ... OSTATOK ...` → расход;
  - `NALICHNYE 125.00 BYN KARTA #1310 ...` → снятие наличных;
  - `ZACHISLENIE NA SCHET KARTA #7880 ... SUMMA 1182.00 BYN` → доход.
- Привязывает операцию к счёту по последним 4 цифрам карты (маска задаётся в веб-приложении).
- Применяет правила категоризации по ключевым словам из Firestore.
- Пишет операцию и атомарно меняет баланс счёта — как это делает веб-приложение.
- Дубликаты отсекаются по хэшу уведомления.
- Нераспознанные пуши складываются в `bankInbox` и видны в настройках веб-приложения.

## Сборка

APK собирается автоматически в GitHub Actions при изменении папки `android-companion`:

1. Откройте вкладку **Actions** → **Android companion** → последний запуск.
2. Скачайте артефакт `financial-planner-companion-debug` (внутри `app-debug.apk`).
3. Установите APK на телефон (разрешите установку из неизвестных источников).

Локальная сборка (нужен JDK 17 и Android SDK):

```bash
cd android-companion
gradle assembleDebug
```

## Настройка на телефоне

1. Откройте приложение «Планировщик — банк».
2. Войдите тем же email/паролем, что и в веб-приложении.
3. «Открыть настройки доступа» → включите «Планировщик: операции из банка».
4. «Выбрать приложения» → отметьте приложение банка.
5. В веб-приложении: Настройки → Автозаполнение из банка → укажите маски карт
   (последние 4 цифры) и правила категоризации.

## Ограничения

- Google Play не публикуем: доступ к уведомлениям — чувствительное разрешение.
- Некоторые банки публикуют уведомление без суммы (скрытый контент) — такие пуши
  попадут во «Входящие банка».
- Пароль не хранится: только refresh-token в приватном хранилище приложения.

## Подпись и обновления

APK подписывается постоянным ключом `keystore/companion.jks` (alias `companion`,
пароль `companion123`, SHA-256 `F6:20:C5:45:AA:45:C8:2C:06:71:0B:F0:34:BF:B3:E4:11:5A:3A:03:4E:3E:1D:99:DB:0F:5A:AD:4B:4D:9D:69`).
Ключ лежит в репозитории намеренно: это личное приложение, зато новые версии
ставятся поверх старой без удаления данных и повторного входа.
