# Планировщик финансов

Веб-приложение для учёта денег и планирования покупок: счета (наличные и карты), доходы и
расходы с категориями/подкатегориями, повторяющиеся операции, календарь остатков на любую
дату и советчик покупок.

Стек: Angular 19 (standalone-компоненты, signals) + Firebase (Auth: email/пароль, Firestore),
Less. Деплой — Firebase Hosting. Структура и паттерны повторяют проект [car-keeper](https://github.com/VitaliyGushenko/car-keeper).

## Возможности

- **Счета** — наличные и карты с текущим остатком; общий баланс считается автоматически.
- **Безопасно потратить сегодня** — главная цифра дашборда: сколько можно потратить,
  чтобы не уйти в минус с учётом всех плановых платежей и ближайшего дохода.
- **Бюджеты по категориям** — месячный лимит задаётся в настройках; прогресс и перерасход
  видны в аналитике и на дашборде.
- **Журнал с поиском и фильтрами** — поиск по заметке, категории, счёту и сумме;
  фильтры по типу, счёту и месяцу; группировка по дням с итогами.
- **Отмена удаления** — операция или правило удаляются сразу, но внизу появляется
  плашка «Отменить» на несколько секунд.
- **Валюта** — выбор валюты интерфейса в настройках профиля (рубль, доллар, евро, тенге и др.);
  меняется отображение, записи не пересчитываются.
- **Операции** — доходы (зарплата, аванс, перевод…), расходы и переводы между своими счетами.
  Категории и подкатегории настраиваются свободно (добавление/удаление в настройках).
  Операцию можно записать будущей датой — она станет плановой.
- **Повторяющиеся операции** — при создании операции отметьте «Повторять регулярно»:
  каждую неделю / месяц / год или свой интервал («каждые 10 дней»). Правила видны
  отдельным списком на странице операций.
- **Календарь остатков** — цветные точки в ячейках показывают, есть ли в этот день
  доходы/расходы; клик по дате открывает остаток на конец дня (для будущего — прогноз
  с учётом всех планов, для прошлого — факт) и список событий.
  Дни с отрицательным остатком подсвечены красным. Стрелки ←/→ — на день, ↑/↓ — на неделю.
- **Аналитика** — графики и статистика за период (месяц / 3 месяца / год / свой диапазон):
  доходы, расходы, сальдо, средние траты в день; круговая диаграмма расходов по категориям;
  столбцы доходов и расходов по месяцам; линия баланса «факт + прогноз»
  (Chart.js, агрегаторы — чистые функции с тестами).
- **Планировщик покупок** — «хочу купить X за Y»: приложение перебирает прогноз и подсказывает
  первую дату, когда покупка не уведёт остаток в минус с учётом всех остальных трат;
  цели можно сохранить и следить, когда по каждой можно покупать. Кнопка «Куплено» списывает
  сумму с выбранного счёта, создаёт операцию в журнале и закрывает цель.
- **Авторизация** Firebase (email/пароль), данные каждого пользователя — только его
  (правила Firestore owner-only).

## Как устроена проекция остатков

Точка отсчёта — фактические балансы счетов «сейчас». Прошлые операции при записи сразу
меняют баланс счёта; операции с будущей датой и вхождения повторяющихся правил участвуют
в прогнозе.

Подтверждение платежей: когда наступает дата плановой операции или вхождения правила,
платёж появляется в блоке **«Ожидают подтверждения»** на дашборде. Там можно указать
фактическую сумму (например, зарплата пришла не полностью) и подтвердить — только после
этого операция попадает в журнал и балансы. Платёж можно пропустить (деньги не пришли)
— для правил даты пропусков запоминаются.

- Будущее: `остаток(D) = сейчас + события из интервала (сегодня, D]`
- Прошлое: `остаток(D) = сейчас − записанные операции из интервала (D, сейчас]`

Движок — чистые функции (`src/app/core/projection.ts`, `advisor.ts`, `pending.ts`) с unit-тестами.

## Запуск для разработки

1. `npm install`
2. В [Firebase Console](https://console.firebase.google.com/project/financial-planner-e1c41):
   - создать **Firestore Database**;
   - включить провайдер **Authentication → Email/Password**.
3. `npm start` → <http://localhost:4200>

## Установка на телефон (PWA)

Приложение — PWA: открывается как сайт, но ставится на домашний экран и запускается
в полноэкранном режиме без адресной строки. Кэшируется только оболочка приложения —
данные Firestore, как и раньше, требуют сети.

- Android/Chrome: меню ⋮ → «Установить приложение».
- iOS/Safari: «Поделиться» → «На экран „Домой“».

Манифест — `src/manifest.webmanifest`, иконки — `src/assets/icons/` (генерируются
`node scripts/gen-pwa-icons.js`). Service worker (`ngsw-config.json`) включается только
в production-сборке; при деплое новой версии в приложении появляется плашка
«Доступна новая версия», которая активирует обновление и перезагружает страницу.

## Голосовой ввод

На странице «Операции» есть кнопка **🎤 Голосом**: скажите фразу — приложение разберёт её
и заполнит форму операции. Сохраняется только после кнопки «Добавить»: распознанные поля
подсвечены, остальное можно поправить.

Примеры фраз:

- «потратил пятьсот рублей на продукты вчера»
- «потратил пятьсот рублей сорок копеек на продукты»
- «купил бензин на две тысячи пятьсот»
- «получил зарплату 120 тысяч»
- «перевёл с карты на наличку три тысячи»
- «такси 350»

Даты тоже распознаются: «сегодня», «вчера», «позавчера», «завтра», «в пятницу»,
«5 ноября», «18-го ноября», «пятого числа», «18.11.2026», «через неделю», «три дня назад».
День недели берётся ближайший (например, «в пятницу» в среду — эта пятница).

Разбор — чистая функция `src/app/core/voice/parse-voice.ts` (тесты рядом), суммы словами
(`пятьсот`, `полторы тысячи`, `120к`, `пять косарей`) разбирает `number-words.ts`.
Распознавание речи — Web Speech API (`speech.service.ts`): работает в Chrome/Edge/Safari,
только по HTTPS и при наличии интернета (в Chrome звук обрабатывается на серверах Google).
В Firefox и части встроенных браузеров распознавания нет — открывается то же окно, где
фразу можно ввести текстом.

## Структура

```
src/app/
  app.config.ts            # провайдеры Firebase (Auth, Firestore, Analytics)
  core/
    auth.service.ts        # email/пароль, автосоздание профиля + сид данных
    auth.guard.ts          # authGuard / guestGuard
    accounts|categories|transactions|recurring|goals.service.ts
    projection.ts          # дневная карта остатков (чистые функции)
    safe-to-spend.ts       # «можно потратить сегодня» (чистая функция)
    budgets.ts             # бюджеты категорий на месяц (чистая функция)
    advisor.ts             # советчик покупок (чистые функции)
    projection.service.ts  # общая проекция как computed из данных
    seed.ts                # стартовые счета и категории
    day-key.ts             # даты как строки «YYYY-MM-DD» (без TZ-болезней)
    voice/                 # голосовой ввод: числа словами, разбор фразы, распознавание
  pages/
    auth/ dashboard/ operations/ calendar/ stats/ planner/ settings/
firestore.rules            # доступ только владельцу данных
```

Данные в Firestore: `users/{uid}` + подколлекции `accounts`, `categories`, `transactions`,
`recurring`, `goals`.
